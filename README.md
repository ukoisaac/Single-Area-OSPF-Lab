# Single Area OSPF Lab

## 📌 Overview
This project demonstrates a Single Area OSPF configuration in Cisco Packet Tracer.

##  Devices Used
- 3 Routers
- 3 Switches
- 3 PCs

## ⚙️ Protocol
- OSPF Area 0

## 🛠 Configuration Steps
1. Assigned IP addresses
2. Enabled OSPF
3. Advertised networks
4. Verified neighbor relationships

## ✅ Verification Commands
- show ip ospf neighbor
- show ip route
- ping
